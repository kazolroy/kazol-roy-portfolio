# Kazol Chandra Roy — Personal Developer Portfolio

A modern, high-performance, and responsive personal developer portfolio web application built with **React 19**, **Tailwind CSS v4**, **React Router v7**, and **Vite**.

## ✨ Features
- **Responsive Navigation Bar**: Scroll-aware active section highlight, responsive mobile drawer menu, and multi-action Resume dropdown.
- **Hero Section**: Clean introductory greeting, status indicator (*Available for Immediate Hire*), single-click resume actions (View, Download PDF, Copy Link), and direct social profile links.
- **About Me Section**: Detailed programming journey, passion for full-stack engineering, professional UNESCO ICT background, and personal interests/hobbies (Cricket, Football, Travel).
- **Categorized Skills Matrix**: Visual confidence ratings (1–5 dots) across Frontend, Backend & Database, and Tools & Deployment, plus foundational programming languages (C, C++, Java, Python).
- **Featured Projects**:
  - **StudioSpace**: Hourly creative workspace & studio booking marketplace (React, Firebase, Node, Express, MongoDB Atlas).
  - **BazarDor (বাজার দর)**: Real-time essential grocery commodity price fluctuation tracker (Next.js App Router, BetterAuth, MongoDB).
- **Dynamic Project Details Pages (`/projects/:id`)**: Comprehensive breakdowns including technical architecture, live links, GitHub client repository, challenges faced & solutions, and future roadmaps.
- **Academic & Experience History**: Timeline of formal university education (B.Sc., HSC, SSC) and professional experience at UNESCO Dhaka and full-stack development.
- **Contact & Direct Messaging**: Direct email, phone, and WhatsApp contact cards with clipboard copy, plus an interactive email inquiry form.
- **ATS-Friendly Web Resume (`/resume`)**: Full, clean, print-ready ATS resume with instant PDF download and print triggers.
- **Modern Footer**: Quick navigation, social links, resume actions, copyright, and smooth back-to-top button.

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/kazolroy/practice-portfolio-ejp-14.git
cd practice-portfolio-ejp-14
```

### 2. Install dependencies
```bash
cd frontend
npm install
```

### 3. Start development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
