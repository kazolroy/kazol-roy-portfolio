## ✨ Features
- **Responsive Navigation Bar**: Scroll-aware active section highlight, responsive mobile drawer menu, and interactive multi-action Resume dropdown.
- **Hero Section**: Clean introductory greeting, status indicator (*Available for Immediate Hire*), single-click resume actions (View, Download PDF, Copy Link), and direct social profile links (GitHub, LinkedIn, WhatsApp, Email).
- **About Me Section**: Comprehensive overview of programming journey (C/C++/Java foundational roots to modern JavaScript/MERN stack), types of work enjoyed, personality traits, and personal hobbies (Cricket, Football, Travel).
- **Categorized Skills Matrix**: Visual graphical confidence ratings (1–5 dots) categorized into Frontend, Backend & Database, and Tools & Deployment, plus foundational programming languages (C, C++, Java, Python).
- **Featured Projects (Card Format & Deep-Dive Details)**:
  - **StudioSpace**: Hourly creative workspace & studio booking marketplace (React, Vite, Firebase Auth, Node, Express, MongoDB Atlas, Vercel).
    - 🔗 [Live Demo](https://studiospace-client-mu.vercel.app) | [GitHub Client](https://github.com/kazolroy/studiospace-client)
  - **BazarDor (বাজার দর)**: Real-time essential grocery commodity price fluctuation tracker (Next.js App Router, Tailwind CSS, DaisyUI, BetterAuth, MongoDB).
    - 🔗 [Live Demo](https://b14-a7-bazar-dor-792d.vercel.app/) | [GitHub Client](https://github.com/kazolroy/B14-A7-Bazar-Dor)
- **Dynamic Project Details Pages (`/projects/:id`)**: Comprehensive deep dive pages for individual projects containing main tech stack used, brief description, live links, GitHub client repository link, challenges faced & technical solutions, and future roadmaps.
- **Academic & Experience History**: Timeline of formal university education (B.Sc. in CSE, HSC from Saidpur Govt. Science College, SSC from Sonapukur Surabhy High School) and professional ICT Support roles at UNESCO Dhaka.
- **Contact & Direct Messaging**: Direct email, phone, and WhatsApp contact cards with clipboard copy buttons, plus an interactive email inquiry form.
- **ATS-Friendly Web Resume (`/resume`)**: Full, clean, print-ready ATS resume with instant PDF download and browser print triggers.
- **Modern Footer**: Brand logo with photo, quick navigation links, social profile buttons, resume download pill, copyright, and smooth back-to-top button.

## 🛠️ Local Development

### 1. Clone the repository
```bash
git clone https://github.com/kazolroy/practice-portfolio-ejp-14.git
cd practice-portfolio-ejp-14
```

### 2. Install dependencies
```bash
cd frontend
npm install
```

### 3. Start development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
